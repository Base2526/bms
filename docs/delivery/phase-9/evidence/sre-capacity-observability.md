# SRE capacity and observability packet

Owners: SRE and Product. Approve pilot volume and concurrency, topology, availability/latency SLO,
queue age and saturation limits, alert thresholds, dashboards, on-call coverage, incident command,
support handoff and capacity margin.

Run load, burst, backlog, dependency latency and partial-outage tests at the approved volume.
Evidence must include configuration, timestamps, results, alert delivery and an owner disposition for
each threshold. A test without a previously approved target cannot close this gate.
