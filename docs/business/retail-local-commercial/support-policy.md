# ร่างนโยบายซัพพอร์ต BMS Retail Local รุ่นนำร่อง

> สถานะ: **ร่างรอเจ้าของอนุมัติ** เวลาให้บริการ SLA และสิทธิแต่ละแผนด้านล่างเป็นข้อเสนอ
> ยังห้ามประกาศกับลูกค้าจนกว่าจะลงนาม

## ช่องทางและเวลาทำการที่เสนอ

| หัวข้อ | ข้อเสนอรออนุมัติ |
| --- | --- |
| ช่องทางหลัก | LINE ทางการสำหรับรับเคส; อีเมลสำหรับเอกสารและหลักฐานที่ไม่เร่งด่วน |
| เวลาทำการ | จันทร์–เสาร์ 09:00–18:00 น. เวลาไทย ยกเว้นวันหยุดที่ประกาศ |
| P1 ร้านขายไม่ได้ | ตอบรับภายใน 1 วันทำการ |
| P2 ฟังก์ชันสำคัญผิดปกติแต่มีทางเลี่ยง | ตอบรับภายใน 1 วันทำการ |
| P3 คำถาม/วิธีใช้ | ตอบรับภายใน 1 วันทำการ |

SLA เป็นเวลา “ตอบรับ/เริ่มวิเคราะห์” ไม่ใช่คำรับประกันเวลาซ่อมเสร็จ และใช้เฉพาะร้านที่มีสิทธิซัพพอร์ต
ร้านฟรีใช้คู่มือและผู้ช่วย AI เป็นหลัก การช่วยจากคนตามแคมเปญรุ่นนำร่องไม่ก่อ SLA ถาวร
ผู้ช่วย AI ใช้ผ่าน LINE OA ของ BMS; ร้านฟรีไม่มีเจ้าหน้าที่ตอบเป็นบริการประจำ
แคมเปญช่วยติดตั้งระยะสั้นใน `retailLocalPricing.leadOffer` ต้องได้รับอนุมัติแยกก่อนเริ่มให้บริการ

## ทะเบียนสิทธิและต้นทุนซัพพอร์ต

ใช้ทะเบียนจำกัดสิทธิ์ที่ฝ่ายบริการดูแลเพื่อผูก LIC- กับชื่อร้าน วันที่เริ่ม/สิ้นสุด MA และเลขใบเสนอราคา
หน้า license ปัจจุบันยังไม่มีวันหมด MA อย่าใช้ trial expiry แทนวันหมด MA หรืออ้างว่า API รองรับแล้ว
ทุกเคสต้องบันทึกจำนวนนาทีจริงและ tag Local Plus ใน CRM ตามสิทธิ์ที่ยืนยันจากทะเบียน
คำนวณนาทีต่อร้านต่อเดือนจากผลรวมเวลา ไม่ใช้ RUNTIME_SEEN แทนเวลาซัพพอร์ต

แบบทะเบียนสิทธิ (เก็บในพื้นที่จำกัดสิทธิ์ ห้ามกรอกข้อมูลจริงใน repository):

| LIC- | ร้าน/ผู้ประสานงานอ้างอิง | แผน | MA เริ่ม | MA สิ้นสุด | หลักฐานรับเงิน/ใบเสนอราคา | ผู้ตรวจ |
| --- | --- | --- | --- | --- | --- | --- |
| ____ | ____ | ____ | ____ | ____ | ____ | ____ |

ห้ามใช้ตารางนี้เป็น kill switch; สิทธิซัพพอร์ตหมดไม่ทำให้ runtime หรือการกู้ข้อมูลหยุด

## ขอบเขตและข้อจำกัด

- ซัพพอร์ตการติดตั้ง runtime, การใช้งาน BMS, update, backup/restore และ activation ตาม target ที่ประกาศ
- เครื่องพิมพ์ ลิ้นชัก สแกนเนอร์ จอลูกค้า และชุดฮาร์ดแวร์ยังไม่ถือว่ารับรองจนมีชื่อรุ่น/OS/release
  ใน evidence matrix ทีมช่วยวิเคราะห์แบบ best effort แต่ไม่รับประกันซ่อมหรือเปลี่ยนอุปกรณ์
- ร้านรับผิดชอบอินเทอร์เน็ต ไฟฟ้า พื้นที่ disk USB/NAS และการเก็บ recovery identity แยกจากเครื่องร้าน
- BMS ไม่ host backup ของร้าน และยังไม่มีการย้ายข้อมูล Local ไป Cloud
- licensing/payment/trial ต้องไม่ใช้เป็นเหตุปฏิเสธการกู้ข้อมูลหรือทำให้ระบบร้านหยุด

## ข้อความสำเร็จรูป

### ติดตั้งไม่ผ่าน

“กรุณาส่งข้อความ error, ขั้นตอนล่าสุด, รุ่น OS และเวลาที่เกิดเหตุ โดยปิดข้อมูลส่วนบุคคล/รหัสลับก่อน
อย่าลบข้อมูลหรือถอน runtime ระหว่างตรวจสอบ เพราะ installer ออกแบบให้ resume จาก checkpoint ได้”

### SmartScreen / Gatekeeper

“ตัวติดตั้งรุ่นนำร่องอาจยังไม่มี trust/reputation ครบ กรุณาตรวจชื่อไฟล์ แหล่งดาวน์โหลด checksum และลายเซ็น
ตาม release ก่อนดำเนินการ อย่าปิดระบบป้องกันทั้งเครื่อง หากตรวจ publisher ไม่ได้ให้หยุดและติดต่อทีม”

### เครื่องพิมพ์ไม่ออก

“ตรวจไฟ สาย/เครือข่าย กระดาษ รุ่นเครื่องพิมพ์ และสถานะใน OS ก่อน อุปกรณ์บางรุ่นยังไม่ผ่านการรับรอง
กรุณาส่งผลทดสอบและรุ่นอุปกรณ์โดยไม่ส่งข้อมูลลูกค้าในใบเสร็จจริง”

### ย้ายเครื่อง

“เตรียม backup เข้ารหัสและ recovery identity ที่เก็บแยก ติดตั้งและ restore บนเครื่องใหม่ จากนั้นขอ
Activation Code ใหม่แล้วเลือก Activate or Transfer ระบบร้านไม่ถูกปิดระหว่างการตรวจย้าย”

### ลืม PIN

“PIN เป็นข้อมูลยืนยันผู้ใช้งาน เราไม่สามารถอ่านหรือบอก PIN เดิมได้ ให้ Administrator ของร้านใช้ขั้นตอน
รีเซ็ตที่มีอยู่ หากไม่มีผู้ดูแลที่ยืนยันได้ ให้เปิดเคสยืนยันสิทธิร้านก่อน ห้ามส่งฐานข้อมูลหรือรหัสผ่านทางแชต”
