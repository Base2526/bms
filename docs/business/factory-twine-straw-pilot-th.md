# แนวทางเดโม BMS: โรงงานเชือกฟางและหลอดพลาสติก

สถานะ: ส่วนขยาย `10.122`–`10.127` อยู่ใน branch สำหรับทดสอบ ยังไม่ใช่การติดตั้งบน production
และยังไม่ใช่ผลยืนยันจากโรงงานจริง ดูข้อจำกัดและขั้นตอน rollout ใน
[operation-production.md](operation-production.md#factory-extension-for-plastic-twine-and-straws-1012210127)

## 1. วางหน่วยและ SKU ตามจุดที่นับสต็อกจริง

| สิ่งที่นับ | หน่วยฐานที่แนะนำ | วิธีใช้ใน BMS |
| --- | --- | --- |
| เม็ด PP, สี masterbatch | GRAM | รับเข้าพร้อมล็อตและตัดเข้า BOM ตามน้ำหนักจริง |
| เชือกฟางที่ขายเป็นม้วนมาตรฐาน | ROLL | หนึ่งม้วนเป็นผลผลิตหนึ่งหน่วย; น้ำหนักเป้าหมายเป็นสเปก/เกณฑ์ QC |
| เชือกที่ขายตามน้ำหนักจริง | GRAM | เลือกสินค้าคนละ SKU/นโยบายจากม้วนมาตรฐาน; ยังไม่มีบิลแบบชั่งน้ำหนักม้วนแปรผันอัตโนมัติ |
| หลอดยังไม่บรรจุ | PIECE | นับเป็นชิ้นถ้าโรงงานเก็บสต็อกระหว่างผลิต |
| หลอดบรรจุถุง | BAG | BOM บรรจุตัดหลอดเป็นชิ้นและวัสดุถุง แล้วรับถุงเป็นล็อตใหม่ |
| ลังที่นับแยก | CARTON | BOM บรรจุลังตัดถุงและวัสดุลัง แล้วรับลังเป็นล็อตใหม่ |

ตัวเลข “100 ชิ้น/ถุง”, “50 ถุง/ลัง”, “1 กก./ม้วน” เป็นตัวอย่างสำหรับเดโมเท่านั้น
ก่อนตั้งค่าจริงต้องยืนยันจำนวนบรรจุ น้ำหนักตามสเปก ของเสีย และวิธีคิดราคากับโรงงาน
หากลังเป็นเพียงหน่วยขาย ไม่ได้เก็บสต็อกเป็นลัง ใช้ `bms_product_packs` คูณหน่วยขาย
แทนการสร้างขั้นผลิตลัง

### ข้อมูลตัวอย่างสำหรับเตรียมเดโม (ต้องเปลี่ยนตามสเปกจริง)

| SKU ตัวอย่าง | หน่วยฐาน | BOM ตัวอย่างต่อผลผลิต | จุดตรวจที่ควรถาม |
| --- | --- | --- | --- |
| `PP-RAW`, `COLOR-RAW` | GRAM | วัตถุดิบที่รับเข้าตามล็อต | สูตรสัดส่วนสีและต้นทุนต่อกรัม |
| `TWINE-ROLL` | ROLL | PP 990 กรัม + สี 10 กรัม → 1 ม้วน | น้ำหนักสุทธิ/ม้วนและเกณฑ์ยอมรับ |
| `STRAW-LOOSE` | PIECE | PP 990 กรัม + สี 10 กรัม → 1,000 ชิ้น | เส้นผ่านศูนย์กลาง สี และจำนวนของคัดทิ้ง |
| `STRAW-BAG` | BAG | `STRAW-LOOSE` 100 ชิ้น + ถุงเปล่า 1 ใบ → 1 ถุง | 100 ชิ้นต่อถุงจริงหรือไม่ |
| `STRAW-CARTON` | CARTON | `STRAW-BAG` 50 ถุง + กล่องเปล่า 1 ใบ → 1 ลัง | 50 ถุงต่อลังจริงหรือไม่ |

SKU ถุงเปล่าและกล่องเปล่าต้องแยกจาก SKU ผลผลิตที่บรรจุแล้ว ถ้าคลังไม่ได้นับ
`STRAW-LOOSE` จริง ให้ลดขั้นระหว่างผลิตลงหลังคุยกับโรงงาน ไม่สร้างสต็อกสมมติ

## 2. ลำดับงานที่เดโมได้

1. ตั้งสาขา, สิทธิ์ผู้ผลิต/ผู้ตรวจคุณภาพ, ความสามารถ `RECIPE` และ `WASTAGE`,
   นโยบายหน่วยฐานสินค้าและต้นทุนเริ่มต้นให้พร้อม เปิดช่องทางขาย `ONLINE_ORDER` ให้ SKU
   ผลผลิตที่จะสร้างออร์เดอร์จากความต้องการลูกค้า แล้วรับเม็ดพลาสติก/สีตาม PO พร้อมล็อต
2. สร้าง Factory BOM แบบมีเวอร์ชัน: เช่น เม็ดพลาสติกและสี → เชือกม้วน หรือ
   เม็ดพลาสติก → หลอดชิ้น → หลอดถุง → หลอดลัง แต่ละขั้นที่นับสต็อกมี SKU และล็อตของตน
   ระบบตรึงหน่วยฐานไว้ใน BOM; หากเปลี่ยนหน่วยสินค้า ต้องทบทวนปริมาณแล้วบันทึก BOM เวอร์ชันใหม่
3. บันทึกความต้องการลูกค้าที่มีอยู่ใน CRM: SKU, จำนวน, กำหนดงาน โดยยังไม่จองสต็อกหรือยืนยันราคา
4. สร้างใบผลิตผูก BOM, ความต้องการ, เครื่องจักรและ Checklist; ดูวัตถุดิบที่ใช้ได้ก่อนเริ่ม
5. โพสต์ผลจริง พร้อมล็อตวัตถุดิบ, จำนวนดี, ของคัดทิ้ง, เวลาเดินเครื่อง, นาทีแรงงานและ kWh
   ระบบตัดวัตถุดิบและรับผลผลิตพร้อมต้นทุนวัตถุดิบใน transaction เดียว
6. ถ้าเปิดนโยบาย QC ผลผลิตล็อตใหม่จะถูกพักทันที ตรวจด้วย Checklist แล้วเสนอปล่อยล็อตหรือทิ้ง
   ให้คนที่สองอนุมัติ; ระหว่างพักขายหรือใช้ต่อไม่ได้
7. เมื่อผลิตครบและล็อตใช้ได้ ให้คนมีสิทธิ์แปลงความต้องการเป็นออร์เดอร์ปกติ
   ระบบตรวจราคาปัจจุบันและสต็อกอีกครั้ง จากนั้นใช้กระบวนการชำระเงินและจัดส่งเดิม

## 3. คำตอบที่ควรใช้ในห้องประชุม

- **ทำได้ใน branch นี้:** BOM โรงงานหลายขั้น, หน่วยวัตถุดิบต่างจากผลผลิต, ล็อตและต้นทุนวัตถุดิบ,
  งานผลิต/Checklist, QC hold, คำขอลูกค้าก่อนมีสต็อก, แปลงเป็นออร์เดอร์เมื่อพร้อม, หลักฐานเครื่องจักร
- **ต้องถามโรงงานก่อนตั้งจริง:** วิธีขายเชือก (ม้วนมาตรฐานหรือชั่งจริง), จำนวนบรรจุของหลอด,
  สเปก/เกณฑ์ QC, จุดที่นับสต็อก, รูปแบบคำสั่งซื้อ/เครดิต, รหัสเครื่องจักร, คนอนุมัติคุณภาพ,
  ราคาขายและภาษี
- **ยังไม่ควรสัญญาว่ารองรับ:** วางแผนกำลังเครื่องแบบ finite capacity, ต้นทุนแปรสภาพจริงเข้า
  inventory valuation, WIP, ผลผลิตร่วม, ใบเสนอราคาสัญญาราคาคงที่, การขายม้วนตามน้ำหนักแปรผัน
  อัตโนมัติ, การรับรองมาตรฐานหรือใช้งาน production โดยไม่ pilot

## 4. เกณฑ์รับงานก่อนเปิดใช้จริง

ยืนยัน migration และสำรองฐานเป้าหมาย; ทดสอบ SKU/หน่วย/แพ็ก/ล็อตจริงหนึ่งสายเชือกและหนึ่งสายหลอด;
ทดสอบวัตถุดิบไม่พอ, ของคัดทิ้ง, กัก QC, คนอนุมัติคนละคน, แปลงออร์เดอร์เมื่อของไม่พร้อม,
คืนสินค้า, โอนสาขาพร้อมล็อต และกระทบต้นทุน/ภาษี; ตรวจบทบาทสาขาและประวัติ audit กับผู้ใช้งานจริง
ก่อนประกาศพร้อมใช้งาน
