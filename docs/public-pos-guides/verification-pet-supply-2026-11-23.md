# หลักฐานทบทวนคู่มือร้านขายอาหารสัตว์ — 23 พฤศจิกายน 2026

คู่มือออนไลน์ `/th/learn/pet-supply` และ `/en/learn/pet-supply` ใช้ track เดิมของศูนย์เรียนรู้ มี 11 บทเรียนสองภาษาและแผนภาพพร้อมคำบรรยายข้อความ ไฟล์ Word/PDF ภาษาไทยสร้างจาก `pet-supply-th.md` ด้วย `build-public-pos-guides.py` และตัวส่งออก PDF เดิม แผนภาพยังไม่มีเสียงบรรยายที่บันทึกสำหรับร้านอาหารสัตว์

## สิ่งที่ตรวจแล้ว

- อ่านเส้นทาง UI และ service ของ Retail POS, Product variants/packs, สินค้าชั่ง, รับเข้าตามสาขา, ล็อต/วันหมดอายุ/FEFO, การคืน/Void, CRM, reorder, restock subscription และ AI tools; คำแนะนำในคู่มือระบุเงื่อนไขการตั้งค่าและสิทธิ์
- `node ../../scripts/run-contract-tests.mjs pure learning-center` ผ่าน 13 ข้อ; `npm run typecheck` และ `npm run build` ผ่านหลังแก้ไขล่าสุด
- เบราว์เซอร์ production build: ไทย/อังกฤษ × 1440/390 px ผ่าน route, card หน้า `/learn`, เมนูบน/มือถือ, สถานะเลือกในแถบ, ลิงก์ Word/PDF, บทแรก และไม่มีแนวนอนล้น
- Word/PDF: 8 หน้า 5 ตาราง ลิงก์ PDF 4 จุด รวมลิงก์ `/th/learn/pet-supply` และ `/en/learn/pet-supply`; render PDF ตรวจภาพทั้ง 8 หน้า ตัวอักษรไทย ตารางและ footer
- `npm run gate` รันแล้ว: release/inventory/typecheck ผ่าน; pure tests 3,890 ผ่าน 1 ไม่ผ่าน 6 ข้าม จึงหยุดก่อน build ข้อที่ไม่ผ่านคือ `admin-client-i18n-contract` พบข้อความอังกฤษสองจุดใน `apps/web/app/(admin)/admin/loading.tsx` ซึ่งมีการแก้ค้างก่อนเริ่มงานนี้; รัน build แยกและผ่าน

## ยังไม่ได้พิสูจน์

- ไม่ได้ทำธุรกรรมจริงในฐานข้อมูลร้านทดสอบหรือ production และไม่ได้ทดสอบเครื่องสแกน เครื่องชั่ง ฉลาก เครื่องพิมพ์ เครือข่าย การรับชำระหรือการคืนเงินจริง
- ตัวเลข 10 → 9, ราคา 120 บาท และเงินกะ 620 บาทเป็นแบบฝึกสมมติ ไม่ใช่ผลธุรกรรมร้านจริง
- การตอบเรื่องสุขภาพสัตว์และอาหารเฉพาะโรคต้องให้ผู้เชี่ยวชาญทบทวนก่อนเปิดช่องทาง AI กับลูกค้าจริง; คู่มือกำหนดให้ส่งต่อสัตวแพทย์ ไม่ถือว่า prompt หรือการทดสอบแบบ pure พิสูจน์คำตอบทุกกรณี
