## เตรียมร้าน สาขา และผู้ใช้

**ผู้ทำ:** เจ้าของร้านหรือผู้ดูแลระบบ ใช้บัญชีของตนเองในร้านทดสอบก่อนรับเงินจริง การอ่านคู่มือนี้ไม่สร้างร้านหรือเปิดสิทธิ์ให้ใคร

1. เข้า [สมัครร้าน BMS](https://jachoei.com/shop-signup) กรอก **ชื่อร้าน** เช่น `ร้านฝึก BMS`, **ประเภทร้าน** ให้ตรงกับเล่มนี้, **ชื่อผู้ใช้ (เจ้าของร้าน)** เป็นชื่อเจ้าของบัญชี, **อีเมล** ที่เจ้าของเปิดอ่านได้ และ **รหัสผ่าน** ที่ตั้งเอง กดสมัครแล้วเปิดลิงก์ยืนยันอีเมลภายใน 30 นาที ร้านจึงถูกสร้างและเปิดใช้ อย่าคัดลอกรหัสผ่านจากตัวอย่างใด ๆ เมื่อเข้าหลังบ้านได้ ให้เปิด **Settings** เพื่อตรวจชื่อร้าน ประเภทร้าน เขตเวลา และข้อมูลกิจการก่อนออร์เดอร์จริง ประเภทร้านเป็นค่าเริ่มต้นของหน้าจอ ไม่ใช่สวิตช์เปิดทุกความสามารถ
2. เปิด **สาขา** ที่ `/admin/locations` ตรวจชื่อ ที่อยู่ และสาขาที่จะขายจริง ตัวอย่างการฝึกใช้ชื่อ **สาขาทดสอบ** ไม่ใช้ที่อยู่หรือเบอร์ของลูกค้าจริง หากมีหลายสาขาให้แยกสต็อกและเครื่องขายตามสาขา อย่าสลับสาขาระหว่างทำตัวอย่าง
3. ไปที่ **ทีมงาน → เพิ่มผู้ใช้** กรอก **ชื่อ** เช่น `แคชเชียร์ฝึก 1`, **อีเมล** ของพนักงานเอง, **บทบาท** ที่ผู้ดูแลมอบหมาย, **รหัสผ่าน** และ **ยืนยันรหัสผ่าน**; โทรศัพท์และรูปเป็นทางเลือก แล้วตรวจที่ **สิทธิ์การใช้งาน** ว่าบทบาทนั้นมีสิทธิ์ตามงาน ผู้ขายต้องมี `pos.sell`; ผู้เปิดกะต้องมี `pos.shift.open` และผู้ปิดกะต้องมี `pos.shift.close`; ผู้ดูแลสินค้าใช้ `product.edit` งานยกเลิก/คืนต้องมีสิทธิ์เฉพาะ อย่าใช้บัญชีหรือ PIN ร่วมกัน การสร้างผู้ใช้ไม่ส่งคำเชิญหรือรหัสผ่านให้อัตโนมัติ
4. ไปที่ **เครื่องขาย + PIN** (`/admin/pos-devices`) เลือกพนักงานแล้วกด **ตั้ง PIN** ส่วนตัว 4–8 หลัก ให้ผู้มีสิทธิ์ลองเลือกชื่อตนเองและใส่ PIN บนเครื่องขายจริง PIN ผิดห้าครั้งจะล็อกชั่วคราว ผู้อนุมัติส่วนลดมือ การ Void และเงินออกลิ้นชักต้องเป็นอีกคนตามสิทธิ์

| รายการสำหรับฝึก | ตัวอย่างที่กรอก | ความหมายและสิ่งที่ตรวจ |
| --- | --- | --- |
| ประเภทร้าน | เลือกประเภทตรงกับเล่มนี้ | เลือกก่อนออร์เดอร์จริงแรก; ตรวจหน้า POS ที่เปิดได้ |
| สาขา | สาขาทดสอบ | เป็นสาขาที่ผูกเครื่องขายและยอดคงเหลือ |
| พนักงาน | แคชเชียร์ฝึก 1 | เป็นบัญชีแยกคน มีสิทธิ์ขายและเปิดกะตามที่มอบหมาย |
| PIN | ตั้งส่วนตัวบนหน้าจอ | ไม่พิมพ์ PIN ตัวอย่างลงคู่มือและไม่ส่งให้ผู้อื่น |

**ผลที่ควรเห็น:** หลังบ้านแสดงสาขาและพนักงานที่สร้างไว้ ผู้ขายที่ไม่มีสิทธิ์จะไม่ผ่านขั้นตอนที่เซิร์ฟเวอร์ตรวจ หากไม่เห็นเมนู ให้ตรวจบทบาท สิทธิ์ และสาขาของบัญชีก่อน

## จับคู่เครื่อง POS และเปิดกะ

**ผู้ทำ:** ผู้ดูแลสร้างเครื่องและจับคู่; แคชเชียร์ที่มี `pos.shift.open` เปิดกะด้วย PIN ของตน

1. เข้า **เครื่องขาย + PIN** ที่ `/admin/pos-devices` กด **เพิ่มเครื่อง** กรอก **รหัสเครื่อง** เช่น `POS-TRAIN-01`, **ชื่อเครื่อง** เช่น `เคาน์เตอร์ฝึก`, และเลือก **สาขา** ที่เป็นสาขาทดสอบ ช่อง **เลขทะเบียนเครื่อง (POS #)** และ **prefix เลขใบเสร็จ** ใช้เฉพาะเมื่อร้านมีข้อมูลที่ถูกต้อง ตรวจสาขาก่อนบันทึก
2. ออกลิงก์หรือ QR สำหรับจับคู่ แล้วเปิดบนเครื่องที่ร้านควบคุมเท่านั้น ตรวจว่า POS แสดงชื่อเครื่องและสาขาตรงกับที่บันทึก ลิงก์และ token เป็นความลับ; ถ้าออก token ใหม่ ตัวเก่าจะใช้ไม่ได้
3. เปิด `/pos` บนเครื่องที่จับคู่แล้ว เลือกชื่อผู้ขายและใส่ PIN ไปแท็บ **กะ** กรอก **เงินตั้งต้นในลิ้นชัก** ตามเงินสดจริงที่ใส่ไว้ทอน ตัวอย่างฝึก `500.00` บาท แล้วกด **เปิดกะ** เงินนี้ไม่ใช่ยอดขาย
4. ตรวจป้ายสถานะว่าเปิดกะแล้ว จากนั้นกลับแท็บขายหรือแท็บงานของประเภทร้าน ถ้าปุ่มเปิดกะใช้ไม่ได้ ให้ตรวจเครื่อง สาขา ชื่อผู้ขาย PIN และสิทธิ์ `pos.shift.open` ตามลำดับ

**อุปกรณ์:** ทดสอบเครื่องสแกนและเครื่องพิมพ์รุ่นที่จะใช้จริง พิมพ์ภาษาไทย QR และใบเสร็จทดสอบให้ผ่านก่อนขายจริง เส้นทาง ESC/POS ลิ้นชัก และการพิมพ์ผ่านมือถือ/เดสก์ท็อปยังต้องพิสูจน์กับอุปกรณ์หน้างาน เว็บ POS ต้องออนไลน์; โหมดออฟไลน์ฉุกเฉินบนมือถือรองรับเฉพาะขายปลีกเงินสดที่เข้าเงื่อนไข ไม่ใช้กับร้านอาหาร บอร์ดเกม หรือร้านยา
