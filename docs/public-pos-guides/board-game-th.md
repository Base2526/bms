# คู่มือเริ่มใช้ BMS POS+ ร้านบอร์ดเกม

## คู่มือนี้เหมาะกับใคร

ใช้กับร้านที่คิดค่าเล่นตามเวลา มีโต๊ะและอาจขายน้ำขนมเพิ่ม ผู้เริ่มต้นจะตั้งโต๊ะกับเรต เปิดกะ เปิดรอบเล่น ปิดกลุ่มบิล รับเงิน และปิดกะ คู่มือนี้ใช้กับผู้จัดการ แคชเชียร์ และผู้ดูแลคลังเกมตามสิทธิ์ ข้อมูลโต๊ะ ราคา ลูกค้า และ SKU เป็นข้อมูลสมมติ

**เตรียมก่อนเริ่ม:** ผังโต๊ะจริง นโยบายค่าเวลา พนักงานที่มีสิทธิ์จัดการรอบเล่นและรับเงิน เครื่อง POS ที่จับคู่ เงินทอน และกล่องเกมที่ตรวจนับแล้ว หากจะทดลองขายขนม ให้เตรียม SKU และสต็อกสาขาด้วย

## ใช้งาน BMS POS+ Desktop สำหรับร้านบอร์ดเกม

**ผู้ทำ:** ผู้ดูแลตั้งโต๊ะ เกม และแพ็กเกจใน Admin; พนักงานที่มีสิทธิ์งานบอร์ดเกมและ `pos.sell` ทำรายการบนเครื่องที่เปิดกะ; ผู้มีสิทธิ์คืนเงินจัดการบิลผิดพลาด ตัวอย่างใช้โต๊ะและแพ็กเกจฝึกเท่านั้น

1. ใน Admin เตรียมผังโต๊ะ เกมที่ให้ยืม และแพ็กเกจ/รอบเล่นตามบทก่อนหน้า ตรวจราคาและกติกาเวลาให้ครบก่อนเปิดหน้าร้าน หน้า Desktop หลัง PIN/เปิดกะมีเมนู **บอร์ดเกม** ซึ่งเปิด workspace บอร์ดเกมในแอป ไม่ใช่หน้าขายปลีกแบบย่อ
2. เปิด **บอร์ดเกม** เลือกโต๊ะที่ว่างและเริ่มรอบเล่น/กลุ่มที่รับผิดชอบเงิน ตรวจเวลาเริ่ม จำนวนคน และแพ็กเกจจากผลที่หน้าจอแสดงก่อนยืนยัน หากโต๊ะมี seating อยู่ อย่าเริ่มรอบซ้อน ให้เปิดกลุ่มเดิมหรือแก้สถานะตามสิทธิ์
3. งานยืมเกม/คืนเกมและการเพิ่มเวลาให้ทำใน workspace บอร์ดเกม ตรวจสถานะเกมและเวลาที่ระบบบันทึกหลังแต่ละการกด บิลค่าเล่นผูกกับ **กลุ่มที่รับผิดชอบเงิน**; โต๊ะเป็นที่นั่ง ไม่ใช่เจ้าของยอดเงิน เมื่อต้องแยกชำระ ให้ตรวจยอดของแต่ละกลุ่ม/บิลที่หน้าจอแสดงก่อนส่งคิดเงิน
4. กดส่งยอดค่าเล่นไปหน้าชำระของ Desktop ตามปุ่มใน workspace แล้วตรวจตะกร้า ยอดรวม และวิธีรับเงิน กดยืนยันครั้งเดียว รอ **ชำระเงินสำเร็จ** และเลขใบเสร็จ จากนั้นกด **กลับหน้าบอร์ดเกม** ตรวจว่ากลุ่มปิดและโต๊ะว่างจริง โต๊ะอาจยังไม่ว่างหากยังมี seating, เกมยืมค้าง หรือกลุ่มอื่นที่ยังเปิดอยู่; ตรวจแต่ละสถานะก่อนรับลูกค้ารอบถัดไป
5. ไป **กะ** นับเงินและปิดกะตามบททั่วไป หากต้องคืนเงินให้เปิดบิลเดิมในเมนู **คืน** และใช้สิทธิ์คืนตามระบบ ไม่แก้เวลา/แพ็กเกจย้อนหลังเพื่อให้ยอดตรง

**เส้นทางที่ตรวจ:** Desktop ใช้ `/pos/app` และ workspace บอร์ดเกมที่ฝังอยู่; งานที่เปิดจาก Admin หรือหน้าคู่มือออนไลน์ยังเป็นหน้า hosted ของเซิร์ฟเวอร์ ภาพที่ 1–2 แสดงเฉพาะขั้นสร้างเครื่องและจับคู่ ไม่ใช่ภาพรอบเล่นจริง ขั้นตอนหลัง PIN ตรวจจากโค้ดและเอกสารโดเมน ยังไม่ทดลองธุรกรรมบนร้านทดสอบ

## ตั้งโต๊ะ เรตเวลา และสินค้าในบิล

**ผู้ทำ:** ผู้จัดการที่มี `board_game.floor.manage` สร้างโต๊ะ และ `board_game.rate.manage` ตั้งเรต; ผู้ดูแลสินค้ามี `product.edit`; ผู้จัดการคลังเกมใช้สิทธิ์จัดการคลังเกม

1. เข้า **โต๊ะบอร์ดเกม** ที่ `/admin/board-game` เลือกสาขาทดสอบ เปิด **ตั้งค่า** สร้างโซน `ชั้น 1` แล้วเพิ่มโต๊ะรหัส `T01` ชื่อ `โต๊ะฝึก 1` จำนวนที่นั่ง 4 ตรวจว่าโต๊ะอยู่ในสาขาและโซนถูกต้อง โต๊ะคือของจริง; รอบเล่นและกลุ่มบิลจะเกิดเมื่อมีลูกค้า
2. ใน **ตั้งค่า → เรต** กดเพิ่มเรตทั่วไป ตั้งชื่อที่ไม่ซ้ำ เช่น `GENERAL ทั่วไป`, ราคา `60` บาทต่อชั่วโมง, ขั้นต่ำ `60` นาที, ปัดทุก `30` นาที, ผ่อนผัน `5` นาที ตรวจผลตัวอย่าง: เล่น 4 นาทีคิดขั้นต่ำ 60 บาท; 65 นาทีคิด 60; 66 นาทีคิด 90 ก่อนส่วนลดและภาษี นโยบายร้านจริงต้องให้ผู้จัดการอนุมัติ
3. ถ้าขายขนม ไป **Products** สร้าง SKU `TRAIN-SNACK-01` ชื่อ `ขนมฝึก`, `DIRECT`, หน่วยฐาน `ชิ้น`, variant `STD`, ราคา `20` บาท เปิดช่องทางขายที่หน้าร้านและรับเข้าที่สาขาทดสอบ 10 ชิ้นผ่าน **Purchase** ตรวจยอดก่อนเปิดโต๊ะ ค่าเวลา/แพ็กเกจ/สิทธิ์เล่นไม่ใช่ SKU สินค้า
4. ถ้าจะให้ยืมเกม เข้า **คลังเกม** ลงชื่อเกมและกล่องแต่ละใบด้วยรหัสเฉพาะ เช่น `GAME-TRAIN-01` ตรวจ QR ด้วยเครื่องอ่าน 2D จริง การยืมคืนกล่องเกมเป็นสถานะคลังเกม ไม่ใช่การขาย SKU หรือตัดสต็อกขนม

| ช่องที่ตั้ง | ตัวอย่างฝึก | ความหมาย |
| --- | --- | --- |
| สาขา / โซน / โต๊ะ | สาขาทดสอบ / ชั้น 1 / T01 | ระบุตำแหน่งนั่งจริง ไม่ใช่กลุ่มผู้จ่ายเงิน |
| ที่นั่ง | 4 | ความจุ ไม่ใช่หลักฐานว่าโต๊ะว่าง |
| เรตทั่วไป | GENERAL ทั่วไป | ใช้กับผู้เล่นตามประเภทที่กำหนด |
| ราคาต่อชั่วโมง | 60 บาท | ฐานคิดเวลาตามกติกาปัดและขั้นต่ำ |
| ขั้นต่ำ / ปัด / ผ่อนผัน | 60 / 30 / 5 นาที | ปรับเวลาที่คิด ไม่ได้ยืนยันว่าเล่นฟรี |
| SKU ขนม | TRAIN-SNACK-01 / 20 บาท | สินค้าขายจริง; ต้องมีสต็อกในสาขา |

## เปิดรอบเล่นและปิดบิลตัวอย่าง

**ผู้ทำ:** พนักงานที่มี `board_game.session.manage` เปิด/ดูแลรอบ; ผู้รับเงินมี `pos.sell`; ผู้ปิดกะมี `pos.shift.close`

1. เปิดกะบนเครื่อง POS ตามขั้นก่อนหน้า เข้าแท็บ **บอร์ดเกม** เลือกโต๊ะ `T01` ที่ว่าง เปิดรอบเล่นสำหรับผู้เล่นฝึกหนึ่งคน เลือกเรตทั่วไปและกลุ่มบิล 1 ตรวจเวลาเริ่มและโหมดคิดเวลา กลุ่มบิลคือผู้รับผิดชอบเงินจริง; หนึ่งโต๊ะอาจมีหลายกลุ่มบิล
2. ถ้าทดสอบเกม ให้เลือกกล่อง `GAME-TRAIN-01` และยืนยันยืมให้รอบนี้ ถ้าขายขนม ให้เลือกกลุ่มบิล 1 ก่อนเพิ่ม `TRAIN-SNACK-01` จำนวน 1 ตรวจยอดขนม 20 บาท สินค้าที่เพิ่มใน tab จะถูกจองสต็อกก่อนชำระ อย่าเพิ่มซ้ำเมื่อจอช้า
3. หลังครบเวลาเล่นที่ตั้งใจทดสอบ ให้คืนกล่องเกมและบัตรค้ำที่ถือไว้ก่อนปิดกลุ่มสุดท้าย เลือก **ปิดบิลกลุ่ม** ตรวจเวลาที่ระบบคิด เรต/แพ็กเกจหรือโปรที่ใช้ และยอดขนม ตัวอย่างเล่น 60 นาที ก่อนส่วนลดและภาษี ค่าเวลา 60 + ขนม 20 = 80 บาท
4. ส่งบิลกลุ่มไปหน้ารับชำระ ตรวจยอด เลือกเงินสด กรอกเงินที่รับจริง `80.00` บาท แล้วกดรับชำระครั้งเดียว รอใบเสร็จและสถานะชำระแล้ว ตรวจขนมในสาขาจาก 10 เหลือ 9 แต่เกมยืมคืนจะกลับเป็นพร้อมยืมตามการตรวจกล่อง
5. ตรวจโต๊ะ `T01` ว่างได้เมื่อทุกกลุ่มบิลชำระและไม่มีรอบ/เกม/บัตรค้าง ถ้ามีอีกกลุ่มยังเล่น โต๊ะยังไม่ว่างแม้กลุ่มแรกจ่ายแล้ว ปิดกะและตรวจเงินสด: เงินตั้งต้น 500 + ยอดรับสุทธิ 80 = 580 บาท หากไม่มีรายการเงินอื่น

**แยกชำระ:** ให้สร้างหรือกำหนดกลุ่มบิลตามผู้จ่ายตั้งแต่ต้น เช่น กลุ่ม 1 และ 2 ปิดและรับเงินทีละกลุ่ม การรวมโต๊ะไม่รวมบิลเอง และกลุ่มที่ปิดยอดแล้วเพิ่มผู้เล่นหรือย้ายรายการใหม่ไม่ได้

## Checklist และสรุปหนึ่งหน้าสำหรับพนักงาน

**ก่อนเปิดร้าน:** ตรวจโซน/โต๊ะว่างจริง → เรตและกติกาเวลา → เกมแต่ละกล่อง → SKU ขนม/สต็อก → PIN/เครื่อง → นับเงินตั้งต้นและเปิดกะ

**ระหว่างวัน:** เปิดรอบ → ตรวจผู้เล่น เรต กลุ่มบิลและเวลา → ยืมเกม/เพิ่มขนมในกลุ่มที่จ่าย → ส่งต่อคำขอ → ก่อนปิดบิลตรวจเวลาจริงและของค้าง

**ก่อนปิดกะ:** รับเกมคืน ตรวจชิ้นส่วน คืนบัตรค้ำ → ปิดและรับชำระทุกกลุ่ม → ตรวจโต๊ะค้าง → นับเงิน → ปิดกะและส่งต่องานค้าง

**Quick reference:** `โต๊ะว่าง` → `เปิดรอบ + ผู้เล่น + เรต + กลุ่มบิล` → `ยืมเกม/เพิ่มสินค้า` → `คืนเกม` → `ปิดบิลกลุ่ม` → `รับชำระ` → `ตรวจโต๊ะ` → `ปิดกะ`

## ขอบเขตก่อนใช้กับร้านจริง

- ค่าเวลา แพ็กเกจ และกล่องเกมไม่ใช่ SKU สินค้า; การมีเลขออร์เดอร์จาก tab ไม่ได้แปลว่ารับเงินแล้ว
- การแจ้งเตือนใกล้หมดเวลาไม่ปิดบิลเอง การแก้เวลาต้องใช้สิทธิ์เฉพาะและตรวจผลบนบิล กลุ่มบิลที่ชำระแล้วแก้ย้อนหลังไม่ได้
- ร้านบอร์ดเกมไม่รองรับ Emergency Offline บนมือถือ เครื่องพิมพ์และ QR ยืมคืนต้องทดลองกับอุปกรณ์จริง ดู [บทเรียนบอร์ดเกมออนไลน์](https://jachoei.com/th/learn/board-game) สำหรับแพ็กเกจ จองโต๊ะ และเงินมัดจำ
