## ตรวจบิล เงินสด และปิดกะ

**ผู้ทำ:** แคชเชียร์ที่มี `pos.shift.close`; ผู้จัดการตรวจรายงานและรายการค้างตามสิทธิ์

1. หลังรับเงินจริง ให้รอผล **ขายสำเร็จ** และเลขใบเสร็จบนจอ กด **ดูใบเสร็จ** หรือ **พิมพ์ใบเสร็จ** ตรวจชื่อสินค้า/บริการ ยอด วิธีรับเงิน และเงินทอน เก็บเลขใบเสร็จของรายการฝึก อย่ากดรับชำระซ้ำเมื่อผลยังไม่ชัด ให้ค้นบิลเดิมก่อน
2. ตรวจผลที่เกี่ยวข้อง: สินค้าที่ตัดสต็อกต้องดูยอดของสาขา; บิลโต๊ะหรือรอบเล่นต้องตรวจสถานะปิด; เงินสดขายจะเข้ายอดลิ้นชักอัตโนมัติ อย่าบันทึกซ้ำเป็นเงินเข้า
3. กลับแท็บ **กะ** ตรวจตะกร้าหรือบิลที่ยังไม่จบ งานคืนเงินภายนอกที่ยังค้าง และเงินเข้าออกที่บันทึกไว้ นับเงินสด **ทั้งหมดในลิ้นชัก** เทียบเงินตั้งต้นกับยอดขายเงินสดสุทธิ เงินทอน เงินคืน และเงินเข้าออกที่บันทึกไว้ ใช้ยอดจริงจากบิล ไม่ใช้ยอดธนบัตรที่ลูกค้ายื่นมาเป็นยอดขาย
4. กรอก **เงินที่นับได้ในลิ้นชัก** แล้วกด **ปิดกะ + นับเงิน** ตรวจรายงานกะและส่วนต่างตามจริง โหมดนับปิดตาจะซ่อนยอดคาดหมายจนปิดกะ ดูย้อนหลังที่ **ประวัติกะของเครื่องนี้** หรือให้ผู้จัดการเปิด `/admin/pos-shifts` ซึ่งเป็นหน้าดูรายงาน ไม่ใช่หน้าปิดกะ

**ถ้าปิดไม่ได้:** ตรวจตะกร้าค้าง บิลที่ยังไม่จบ รายการเบิกเงินที่ยังไม่ปิดยอด ผู้ขาย/PIN และการเชื่อมต่อ ห้ามล้างรายการหรือกดซ้ำเพียงเพื่อให้ปุ่มผ่าน

## เมื่อรายการไม่ผ่านหรือผลชำระไม่ชัด

| อาการ | ตรวจเป็นอันดับแรก | ทำต่ออย่างปลอดภัย |
| --- | --- | --- |
| สแกนแล้วไม่พบสินค้า | บาร์โค้ด SKU variant และช่องทางขายหน้าร้าน | ค้นชื่อสินค้าใน POS; ให้ผู้ดูแลแก้สินค้า/ป้าย อย่าสร้างสินค้าใหม่ซ้ำทันที |
| PIN หรือสิทธิ์ไม่ผ่าน | ชื่อผู้ขาย กะ สิทธิ์ สาขา และการล็อกชั่วคราว | ให้ผู้ดูแลตรวจ Users / Permissions / POS Devices; อย่าใช้ PIN ของผู้อื่น |
| กดรับเงินแล้วไม่เห็นผลแน่ชัด | เลขใบเสร็จ ประวัติบิล และยอดเงินจริง | เปิดบิลเดิมและรีเฟรชก่อนลองอีกครั้ง; เก็บเวลา เครื่อง และเลขอ้างอิงส่ง Support หากยังไม่ชัด |
| ต้องยกเลิกหรือคืนสินค้า | บิลเดิม จำนวนที่คืน สภาพสินค้า และผู้อนุมัติ | ใช้แท็บคืน/ยกเลิกตามสิทธิ์ บันทึกเหตุผล; เงินสดคืนได้ตามยอดที่ระบบจัดสรร ส่วน QR/บัตร/Wallet อาจค้างรอการคืนภายนอก |
| พิมพ์ไม่ออก | ผลขายสำเร็จและเลขบิลก่อน | ตรวจเครื่องพิมพ์ กระดาษ และช่องทางพิมพ์ แล้วพิมพ์ซ้ำจากบิลเดิม; อย่ารับเงินซ้ำ |

**ข้อควรจำ:** ใบเสร็จ PDF ที่ส่งทางอีเมลไม่ใช่ e-Tax และยังไม่มีผู้ให้บริการนำส่ง e-Tax ที่ยืนยันพร้อมใช้จริง การคืนสินค้า สถานะเงินคืน และเอกสารภาษีเป็นคนละผลลัพธ์ ให้ตรวจแต่ละอย่างแยกกัน
