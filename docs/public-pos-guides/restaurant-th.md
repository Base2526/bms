# คู่มือเริ่มใช้ BMS POS+ ร้านอาหารและคาเฟ่

## คู่มือนี้เหมาะกับใคร

ใช้กับร้านที่เปิดบิลโต๊ะหรือ TAKEAWAY และส่งรายการเป็นรอบเข้าครัวผ่าน **Restaurant POS** และ **Kitchen Board** คาเฟ่ที่ขายหน้าเคาน์เตอร์โดยไม่มีบิลเปิดหรือรอบครัวให้ใช้ [คู่มือค้าปลีก](https://jachoei.com/th/learn/retail) เล่มนี้สอนตั้งโต๊ะ/เมนู เปิดกะ ส่งครัว รับเงิน ตรวจบิลและสต็อก แล้วปิดกะด้วยข้อมูลสมมติ

**เตรียมก่อนเริ่ม:** สาขา ผังโต๊ะ เมนูหนึ่งรายการ สถานีครัว พนักงาน POS/ครัวที่มีสิทธิ์ เครื่องขายที่จับคู่ และเงินทอน ทดลองในร้านทดสอบก่อนรับเงินจริง

## ใช้งาน BMS POS+ Desktop สำหรับร้านอาหารและคาเฟ่

**ผู้ทำ:** ผู้ดูแลตั้งผังโต๊ะ เมนู สูตร และสถานีครัวใน Admin; พนักงานที่มีสิทธิ์ Restaurant POS เปิดบิล/ส่งครัว; แคชเชียร์ `pos.sell` รับเงิน; ผู้อนุมัติที่มีสิทธิ์ยกเลิกตรวจเหตุผลและผลคืนเงิน

1. หลังเลือกพนักงานและเปิดกะ แอปของร้านอาหารพาไป `/pos/restaurant` ซึ่งเป็นหน้าร้านอาหารแบบ hosted ภายใน Desktop ตรวจสาขาและเลือกงาน **ผังโต๊ะ**, **สั่งอาหาร**, หรือ **ครัว** ตามหน้าจอ อย่าใช้ **ขาย** แบบย่อแทนบิลโต๊ะ
2. สำหรับ **DINE_IN** เลือกโต๊ะว่างบนผัง เปิดบิล แล้วเลือกเมนูและ modifier ที่หน้าจออนุญาต ตรวจจำนวน ราคา และรายการที่ **ยังไม่ส่งครัว** ก่อนกดส่งรอบครัว หนึ่งรอบส่งเป็นธุรกรรมของบิล; การรับเงินเองไม่สร้างตั๋วครัว สำหรับ **TAKEAWAY** เปิดบิลแบบรับกลับแทนโต๊ะ ตรวจชื่อ/หมายเลขรับของที่ระบบให้ตามสภาพแวดล้อม
3. เปิด **ครัว** หรือ Kitchen Board เพื่อตรวจตั๋วและสถานะอาหารหลังส่งรอบ ถ้าไม่เห็นงานให้ตรวจว่ากดส่งแล้ว สถานีครัว/เมนูเปิดใช้ และการเชื่อมต่อยังดี บิลเปิดสามารถมีหลายรอบและหลายรายการที่ยังไม่ส่ง จึงต้องตรวจทั้งบิลก่อนคิดเงิน
4. ที่บิลเดิมเปิดหน้าคิดเงิน ตรวจยอดรวมและรายการที่ยกเลิกแล้ว เลือกวิธีชำระที่ตั้งค่าไว้และกดยืนยันครั้งเดียว รอผลบิลปิดและใบเสร็จ หากต้องแยกบิล ให้ตรวจยอดของแต่ละใบก่อนปิด; โต๊ะอาจมีหลายบิลเปิด การแตะโต๊ะต้องเลือกใบที่ต้องการ
5. หากรายการอาหารผิด ให้ใช้ปุ่มยกเลิกของรอบ/บรรทัดพร้อมเหตุผลและสิทธิ์ตามหน้าจอ การยกเลิกหลังขายหรือคืนเงินใช้เส้นทางคืนของระบบ ห้ามลบบรรทัดใน Admin เพื่อหลบหลักฐาน จากนั้นไป **กะ** ตรวจบิลเปิดและนับ/ปิดกะ

**ข้อที่ต้องเห็นจริงก่อนใช้ร้าน:** ความพร้อมเครื่องพิมพ์ครัว เสียง/แจ้งเตือน และการเชื่อมต่ออุปกรณ์ยังต้องทดสอบกับสาขา ภาพที่ 1–2 ยืนยัน UI สร้างเครื่องและจับคู่เท่านั้น; หน้าร้านอาหารและผลธุรกรรมตรวจจากโค้ด ยังไม่ได้จับภาพร้านทดสอบ

## ตั้งผังโต๊ะ สถานีครัว และเมนู

**ผู้ทำ:** ผู้จัดการที่มี `restaurant.floor.manage` จัดผัง; ผู้ดูแลสินค้าที่มี `product.edit` ตั้งเมนูและสถานี; พนักงานครัวใช้สิทธิ์อัปเดตงานครัวตามบทบาท

1. เข้า **จัดผังร้าน** ที่ `/admin/restaurant-floor` เลือกสาขาทดสอบ สร้างโซน `หน้าร้าน` เพิ่มโต๊ะรหัส `T01` ชื่อ `โต๊ะฝึก 1` จำนวนที่นั่ง 2 แล้วตรวจบนผังว่าอยู่สาขาถูก บิล **DINE_IN** ต้องมีโต๊ะจริง ส่วน **TAKEAWAY** ไม่มีโต๊ะและไม่ใช้ QR โต๊ะ
2. ไปที่ **Stock models** ที่ `/admin/stock-models` สร้างสถานีครัว `เครื่องดื่มฝึก` เลือกขอบเขตสาขาให้ตรง แล้วทดสอบจอ **Kitchen Board** ที่ `/admin/kitchen` ว่าผู้ทำงานเห็นสถานี เครื่องพิมพ์แยกสถานีเป็นงาน pilot ของ Desktop บางเส้นทาง; ใช้จอครัวเป็นรายการงานหลัก
3. ใน **Products** สร้างเมนู `น้ำดื่มขวดฝึก` SKU `TRAIN-DRINK-001` เลือก template ที่เหมาะกับร้านอาหาร แต่ตั้ง **รูปแบบสต็อก** `DIRECT`, **หน่วยฐาน** `ชิ้น`, variant `STD`, **ราคาขาย** `20.00`, **ช่องทางขาย** `RESTAURANT_POS` และผูกสถานี `เครื่องดื่มฝึก` ตรวจ VAT ตามบัญชีร้าน หากฟอร์มแสดงช่องอื่น ให้กรอกตามข้อมูลจริง ไม่ใช้ข้อมูลตัวอย่างเป็นกฎภาษี
4. ไปที่ **Purchase** สร้างและรับสินค้า SKU นี้จำนวน 10 ชิ้นเข้าสาขาทดสอบ ตรวจยอดคงเหลือ ก่อนเริ่มบิล สำหรับเมนูปรุงจากวัตถุดิบจริง ให้เปลี่ยนไปใช้ `RECIPE` แล้วตั้งสูตรและหน่วยวัตถุดิบต่อหนึ่งจานใน Stock models ก่อนทดลองขาย อย่าใช้ `DIRECT` กับอาหารที่ต้องตัดหลายวัตถุดิบ

| ช่อง | ตัวอย่างฝึก | ความหมาย |
| --- | --- | --- |
| โซน / โต๊ะ / ที่นั่ง | หน้าร้าน / T01 / 2 | ผังโต๊ะ DINE_IN ของสาขานี้ |
| สถานีครัว | เครื่องดื่มฝึก | ที่แสดง ticket งาน ไม่ใช่คลังสต็อกอีกแห่ง |
| SKU / เมนู | TRAIN-DRINK-001 / น้ำดื่มขวดฝึก | รายการที่พนักงานเลือกในบิล |
| สต็อก / ช่องทาง | DIRECT / RESTAURANT_POS | ตัดของตรงและแสดงใน Restaurant POS |
| หน่วย / variant / ราคา | ชิ้น / STD / 20.00 บาท | หนึ่งขวดต่อหนึ่งรายการ |
| จำนวนรับเข้า | 10 ชิ้น | ยอดพร้อมขายก่อนทำรายการฝึก |

## เปิดบิล ส่งครัว และรับเงินตัวอย่าง

**ผู้ทำ:** พนักงานที่มี `pos.sell` ใช้ `/pos/restaurant` เพื่อเปิดบิลและส่งครัว; ผู้ทำครัวมี `restaurant.kitchen.update`; ผู้รับเงินใช้ PIN และกะที่เปิด

1. เปิดกะด้วยเงินตั้งต้น 500 บาท เข้า **POS ร้านอาหาร** ที่ `/pos/restaurant` เลือกโต๊ะ `T01` แล้ว **เปิดบิล** แบบ DINE_IN ตรวจจำนวนแขกและชื่อโต๊ะ หากเป็นลูกค้ารับกลับให้เปิด TAKEAWAY แยกจากโต๊ะ
2. เลือกเมนู `น้ำดื่มขวดฝึก` จำนวน 1 ตรวจรายการร่าง ราคา 20 บาทและสถานี แล้วกด **ส่งครัว** หนึ่งครั้ง รอผลสำเร็จ จึงเปิด **Kitchen Board** ตรวจ ticket ของ `T01` และอัปเดตสถานะเมื่อเตรียม/ส่งจริง ลูกค้าสั่งเพิ่มให้สร้างรอบใหม่ ไม่กดส่งรอบเดิมซ้ำ
3. กลับบิล ตรวจว่าไม่มีรายการร่างที่ยังไม่ส่งครัว เลือก **คิดเงิน** ตรวจยอดที่เซิร์ฟเวอร์แสดง เลือกเงินสด รับ `20.00` บาท แล้วกดยืนยันรับชำระครั้งเดียว รอใบเสร็จ ตรวจสถานะบิลชำระแล้วและโต๊ะว่างตามผลรายการ
4. ตรวจ SKU ในสาขาทดสอบจาก 10 เหลือ 9 และรายงานกะ หากไม่มีเงินอื่น เงินสดในลิ้นชักควรเป็น 500 + 20 = 520 บาท ก่อนปิดกะ

**รายการที่ผิด:** ก่อนส่งครัวให้แก้รายการร่าง; หลังส่งครัวให้ใช้ขั้นตอนยกเลิกรายการพร้อมเหตุผลและผู้อนุมัติเมื่อระบบกำหนด การยกเลิกทั้งบิลต้องบอกเหตุผล และหลังส่งครัวต้องให้ผู้มี `pos.void` อีกคนอนุมัติ อย่าลบ ticket หรือปรับสต็อกมือเพื่อซ่อนรายการ

## Checklist และสรุปหนึ่งหน้าสำหรับพนักงาน

**ก่อนเปิดร้าน:** ตรวจโต๊ะ/TAKEAWAY → เมนูและวัตถุดิบ/สต็อก → สถานีและจอครัว → เครื่อง/PIN → เงินตั้งต้น → เปิดกะ

**ระหว่างวัน:** เปิดบิล → เลือกเมนูและตัวเลือก → ตรวจร่าง → ส่งครัวเป็นรอบ → ครัวอัปเดตงาน → ตรวจรายการที่ยังไม่ส่ง → คิดเงิน → ใบเสร็จ

**ก่อนปิดกะ:** ตรวจบิลเปิดและ ticket ค้าง → งานยกเลิกและคืนเงิน → นับเงินสด → ปิดกะ → ส่งมอบบิล/โต๊ะที่ยังค้างให้กะถัดไป

**Quick reference:** `DINE_IN เลือกโต๊ะ / TAKEAWAY ไม่ใช้โต๊ะ` → `เปิดบิล` → `เพิ่มเมนู` → `ส่งครัว` → `ตรวจ Kitchen Board` → `คิดเงิน` → `รับชำระ` → `ตรวจใบเสร็จและสต็อก` → `ปิดกะ`

## ขอบเขตก่อนใช้กับร้านจริง

- Restaurant POS ใช้บิลเปิดและครัวต่างจาก POS ขายปลีก คาเฟ่เคาน์เตอร์ทั่วไปให้ใช้ flow ค้าปลีก หากใช้สูตรต้องทวนหน่วยวัตถุดิบและจำนวนต่อจานจริง
- QR โต๊ะเป็นคำขอสั่งที่พนักงานต้องรับก่อนเข้าครัว ไม่ใช่ QR รับเงิน บิล TAKEAWAY ไม่มี QR โต๊ะ
- ร้านอาหารไม่มี Emergency Offline บนมือถือ และงานพิมพ์ครัว/ใบเสร็จต้องทดสอบกับอุปกรณ์จริง ดู [บทเรียนร้านอาหารออนไลน์](https://jachoei.com/th/learn/restaurant) สำหรับแยกบิล รวมบิล คิว และออร์เดอร์ออนไลน์
