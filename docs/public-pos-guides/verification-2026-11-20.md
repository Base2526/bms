ภาพที่เผยแพร่ในคู่มือคือ `images/admin-test-pos-device.jpg` จาก Admin ของร้านทดสอบ
และ `images/desktop-setup-macos.jpg` จากแอปจริงบน macOS โดยแสดงเฉพาะขั้นสร้างเครื่อง/จับคู่
ไม่มีภาพเฉพาะร้านหรือภาพ PIN/ขาย/ใบเสร็จ/ปิดกะ เพราะแอปยังไม่ได้จับคู่กับร้านทดสอบ
อย่านำภาพของร้านค้าปลีกไปแทนหน้าจอร้านอื่น

ขั้นต่อไปเมื่อมีเครื่องทดสอบและ PIN ที่ผู้ใช้ตั้งเอง: จับคู่แอปกับสาขาทดสอบ, เปิดกะ,
ทดลอง flow แยกแต่ละ archetype พร้อมข้อมูลสมมติ, ตรวจผลจากบิล/สต็อก/รายงานกะ,
ถ่ายภาพที่ปิดบังข้อมูลส่วนตัว, เพิ่มภาพและสถานะในแต่ละเล่ม แล้วสร้าง Word/PDF ใหม่
ก่อนเผยแพร่รุ่นที่อ้างผลธุรกรรมจริง
