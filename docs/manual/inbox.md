# คู่มือการใช้งาน: กล่องข้อความรวม (Inbox)

หน้าที่เกี่ยวข้อง: `/admin/inbox` · สิทธิ์ที่ใช้: `inbox.view` / `inbox.reply` / `inbox.manage` / `inbox.assign`
อ้างอิงโค้ด: `apps/web/lib/bms/inbox.ts` · `apps/web/app/(admin)/admin/inbox/page.tsx` ·
`apps/web/graphql/bmsInbox.ts` — ดูสถาปัตยกรรมเต็มที่ [../ui/customer360.md](../ui/customer360.md)

## ทำไมถึงมีฟีเจอร์นี้ / ประโยชน์ที่ได้รับ

ก่อนหน้านี้ลูกค้าทักมาได้หลายช่องทาง (LINE, Facebook, Instagram, TikTok, เว็บแชท) พนักงานต้องสลับหน้าจอ
แอปหลายตัวเพื่อตอบแต่ละช่องทาง ทำให้:

- **ตอบช้า / ตอบตกหล่น** เพราะไม่มีที่เดียวที่เห็นข้อความค้างตอบทุกช่องทางพร้อมกัน
- **ไม่รู้ว่าใครถือแชทลูกค้ารายนี้อยู่** เกิดปัญหาแชทซ้ำซ้อนหรือไม่มีใครรับผิดชอบ
- **ไม่เห็นบริบทลูกค้า** ตอนตอบแชท ไม่รู้ว่าลูกค้าเคยสั่งอะไรมาก่อน มีสลิปค้างตรวจไหม มีพัสดุที่ต้องส่งไหม

**Inbox แก้ปัญหานี้โดย**:

1. **รวมทุกช่องทางไว้ที่เดียว** — พนักงานเปิดหน้าเดียว เห็นแชทจากทุกช่องทาง ไม่ต้องสลับแอป
2. **AI ตอบลูกค้าอัตโนมัติได้ก่อน** (รับออร์เดอร์ ตอบคำถามสินค้า ฯลฯ) และ **พนักงานตอบต่อเองได้ทันที**
   ในแชทเดียวกันเมื่อไหร่ก็ได้ ไม่ต้องรอ AI จบงานก่อน
3. **มอบหมายงานชัดเจน** — ระบบสุ่มมอบหมายพนักงานให้อัตโนมัติตามภาระงาน (round-robin) และพนักงานที่มีสิทธิ์
   สามารถโอน/เพิ่มผู้ช่วยดูแลแชทได้ ไม่มีแชทที่ "ไม่มีเจ้าของ"
4. **เห็นบริบทลูกค้าโดยไม่ต้องสลับหน้าจอ** — แผง Customer 360 ข้างแชทโชว์ประวัติออร์เดอร์/สลิปที่รอตรวจ/
   สถานะพัสดุของลูกค้าคนนั้นแบบเรียลไทม์
5. **ตรวจสอบย้อนหลังได้** — ทุกการกระทำ (ตอบ มอบหมาย เปลี่ยนสถานะ ติดแท็ก) ถูกบันทึกลง audit log และ
   แสดงในแท็บ Timeline ของแชทนั้น

## แนวคิดหลักที่ต้องเข้าใจก่อนใช้งาน

| คำศัพท์ | ความหมาย |
| --- | --- |
| **Conversation (การสนทนา)** | แชท 1 เส้นทาง = 1 ร้าน + 1 ช่องทาง + 1 ลูกค้า (เช่น ลูกค้า A ทัก LINE = หนึ่งการสนทนา ทัก Facebook อีกเบอร์ = อีกหนึ่งการสนทนา) |
| **สถานะการสนทนา** | `OPEN` (เปิดอยู่/รอดำเนินการ) · `PENDING` (รอลูกค้าตอบกลับ/รอเอกสาร) · `CLOSED` (จบเรื่องแล้ว) |
| **ผู้รับผิดชอบหลัก (assigned)** | พนักงานที่ระบบมอบหมายให้ดูแลแชทนี้ — มอบหมายอัตโนมัติครั้งแรกที่มีแชทเข้ามา |
| **ผู้ช่วยดูแล (helper)** | พนักงานคนอื่นที่ถูกเพิ่มเข้ามาช่วยดูแลแชทเดียวกัน (กรณีต้องการคนช่วยตอบ) |
| **AI ตอบอัตโนมัติ** | ข้อความที่ขึ้นต้นด้วยไอคอน/ป้าย AI คือคำตอบที่ระบบ AI ตอบให้ลูกค้าโดยอัตโนมัติ — พนักงานตอบแทรกเองได้ตลอดเวลา |
| **แท็ก (Tags)** | ป้ายกำกับที่พนักงานติดเองเพื่อจัดหมวดหมู่แชท (เช่น "รอสลิป", "VIP") |

## วิธีการใช้งาน

### 1. เปิดรับแชท

- ไปที่เมนู **กล่องข้อความ (Inbox)** ในแถบด้านซ้าย
- เปิดสวิตช์ **"พร้อมรับแชท"** ที่มุมบนของคอลัมน์รายการสนทนา เพื่อให้ระบบมอบหมายแชทใหม่มาให้คุณได้
  (ถ้าปิดสวิตช์นี้ ระบบจะไม่ส่งแชทใหม่มาให้อัตโนมัติ)

### 2. หารายการสนทนาที่ต้องตอบ (คอลัมน์ซ้าย)

- ใช้แท็บกรองสถานะ: **ทั้งหมด / เปิด / รอดำเนินการ / ปิดแล้ว**
- ใช้ช่องค้นหาเพื่อหาแชทตามชื่อลูกค้า/ข้อความ
- เปิดสวิตช์ **"เฉพาะของฉัน"** เพื่อดูเฉพาะแชทที่คุณเป็นผู้รับผิดชอบ
- สังเกต **ป้ายด่วน** ที่หน้ารายการ เช่น "รอตอบ", "มีสลิปรอตรวจ", "รอจัดส่ง", "ถามสินค้า" — ใช้จัดลำดับ
  ว่าควรตอบแชทไหนก่อน
- แต่ละแถวโชว์ไอคอนช่องทาง (LINE/FB/IG/TikTok/เว็บ) และรูปพนักงานที่รับผิดชอบแชทนั้น

### 3. ตอบแชท (คอลัมน์กลาง)

- คลิกเลือกรายการสนทนา ระบบจะเปิดหน้าต่างแชทตรงกลาง
- พิมพ์ข้อความในช่องด้านล่าง แนบอีโมจิ รูปภาพ หรือไฟล์ได้ (แนบได้ครั้งละ 1 ไฟล์ต่อการส่ง)
- ปุ่ม **แนบสินค้า** — เลือกสินค้าจากแคตตาล็อกเพื่อส่งลิงก์/รูปสินค้าให้ลูกค้าดูในแชทโดยตรง
- ปุ่ม **แนบคูปอง** (ต้องมีสิทธิ์ `coupon.view`) — เลือกคูปองส่งให้ลูกค้า ระบบจะผูกคูปองเข้ากระเป๋าคูปอง
  ของลูกค้าคนนั้นให้อัตโนมัติพร้อมลิงก์ใช้งาน
- ระบบมีข้อความแนะนำ/ปุ่มลัดคำตอบที่คาดเดาจากคำสำคัญในข้อความล่าสุดของลูกค้า ช่วยร่างคำตอบเร็วขึ้น
  (เป็นคำแนะนำจากกฎเบื้องต้น ไม่ใช่ AI สร้างคำตอบสด — พนักงานควรตรวจสอบก่อนส่งเสมอ)
- **ตอบแทรกระหว่าง AI คุยอยู่ได้ทันที** — ไม่ต้องรอ AI จบบทสนทนา พิมพ์แล้วส่งได้เลย

### 4. ดูข้อมูลลูกค้าโดยไม่ต้องออกจากหน้าแชท (คอลัมน์ขวา — Customer 360)

แท็บ **ลูกค้า** (ต้องมีสิทธิ์ `customer.view`) แสดง:

- ประวัติออร์เดอร์ล่าสุดของลูกค้าคนนี้
- สลิปโอนเงินที่รอตรวจ (ถ้ามี)
- สถานะการจัดส่งของพัสดุที่ยังไม่ถึงมือลูกค้า

แท็บ **Timeline** (ต้องมีสิทธิ์ `inbox.view`) รวมทุกเหตุการณ์ของแชทนี้เรียงตามเวลา: ข้อความ, โน้ตภายใน,
ออร์เดอร์ที่เกิดจากแชทนี้, และการกระทำของพนักงาน (มอบหมาย/เปลี่ยนสถานะ/ติดแท็ก)

แท็บ **โน้ต** — บันทึกข้อความภายในทีม (ลูกค้าไม่เห็น) พิมพ์ `@ชื่อพนักงาน` เพื่อแท็กเรียกให้คนอื่นมาดู

### 5. มอบหมาย / โอนแชท (ต้องมีสิทธิ์ `inbox.assign` หรือ `inbox.reply`)

- ที่ส่วนหัวของหน้าต่างแชท กดเปลี่ยนผู้รับผิดชอบหลัก หรือเพิ่ม/ลบผู้ช่วยดูแล
- ใช้เมื่อ: พนักงานคนเดิมไม่ว่าง, ต้องการให้หัวหน้าช่วยตอบเคสยาก, หรือโอนงานก่อนเลิกกะ

### 6. เปลี่ยนสถานะ / ติดแท็ก / ปิดแชท (ต้องมีสิทธิ์ `inbox.manage`)

- เปลี่ยนสถานะเป็น **รอดำเนินการ** เมื่อรอเอกสาร/รอลูกค้าตอบกลับ
- เปลี่ยนเป็น **ปิดแล้ว** เมื่อจบเรื่อง (ยังเปิดดูย้อนหลังได้เสมอ ไม่ได้ลบ)
- ติดแท็กเพื่อจัดหมวดหมู่ ช่วยกรองค้นหาทีหลัง

## ข้อควรรู้ / ข้อจำกัดปัจจุบัน

- **ลูกค้าคนเดียวทักมาคนละช่องทาง = ระบบเห็นเป็นคนละคนกัน** จนกว่าจะมีคนไปกด "ผสาน" ที่หน้า
  `/admin/customers` (ต้องมีสิทธิ์ `customer.edit`) — ถ้าเห็นประวัติลูกค้าไม่ครบ ให้สงสัยว่าอาจยังไม่ได้ผสาน
- ช่องทาง **เว็บแชทและ TikTok** ตอนนี้เป็นการบันทึกอย่างเดียว (ยังไม่มี API ส่งข้อความออกจริงจากระบบ)
  ส่วน **LINE / Facebook / Instagram** ส่งออกไปหาลูกค้าจริงได้ทันที
  ที่ตอบไป หรือยิงคำถามซ้ำที่ระบบตอบไม่ได้ ให้ตรวจสอบสถานะแชทก่อนตอบซ้ำ
- ออร์เดอร์จาก Shopee/Lazada ยังไม่เชื่อมเข้า Inbox/Customer 360 (อยู่ระหว่างพัฒนา)
- มีเครื่องมือ **`/admin/inbox/realtime-diagnostics`** สำหรับแอดมิน/platform admin ใช้ตรวจสอบระบบเรียลไทม์
  เบื้องหลัง — ไม่ใช่ส่วนหนึ่งของการใช้งานประจำวัน พนักงานทั่วไปไม่ต้องเข้าเมนูนี้
