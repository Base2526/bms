คลิปสั้นแนวตั้งสำหรับโปรโมตให้คนเข้ามาใช้ AI-BMS (TikTok / Reels / YouTube Shorts)

|---|---|
| รูปแบบ | แนวตั้ง 9:16 · ~50 วินาที · มี caption ตลอด (คนดูแบบปิดเสียง) |

| CTA | เริ่มใช้ฟรีวันนี้ → `/shop-signup` |

## 1) 📖 STORY

**Logline:** แม่ค้าออนไลน์คนหนึ่งจมอยู่กับแชตหลายร้อยข้อความข้ามหลายแพลตฟอร์มจนพลาดออเดอร์และขายของที่หมดสต็อก — จนได้เจอ AI-BMS ที่เปลี่ยน "ทุกบทสนทนา" ให้กลายเป็นออเดอร์ สต็อก ชำระเงิน และจัดส่งอัตโนมัติ ทำให้เธอกลับมาควบคุมธุรกิจ (และชีวิต) ได้อีกครั้ง

**Synopsis (3 องก์):**
- **องก์ 1 – ปัญหา:** ดึกแล้ว มือถือเด้งไม่หยุดจาก LINE/TikTok/FB โน้ตแปะเต็มโต๊ะ Excel รก ตอบไม่ทัน ลูกค้าหาย ขายของที่เพิ่งหมด
- **องก์ 2 – ทางออก:** AI-BMS เข้ามา — ทุกช่องทางรวมในอินบ็อกซ์เดียว AI ตอบ เช็คสต็อก สร้างออเดอร์ ตรวจสลิป จัดส่ง แดชบอร์ดขึ้นสด
- **องก์ 3 – ผลลัพธ์:** แม่ค้ายิ้ม จิบกาแฟ ธุรกิจเดินเอง ยอดโต — ปิดด้วยโลโก้ + CTA

## 3) 📝 SCRIPT + 4) 💬 DIALOGUE (VO + บนจอ, ตามเวลา)

> **VO** = เสียงบรรยาย (ผู้หญิงไทย น้ำเสียงเป็นกันเอง มั่นใจ) · **SUB** = ข้อความบนจอ · **CHAT** = บทแชตในแอป

**S1 (0–5s)**
- VO: "ขายของออนไลน์ทั้งวัน… แต่แชตก็ยังท่วมหัว"
- SUB: `ขายของออนไลน์… แต่ทำไมเหนื่อยขนาดนี้? 😮‍💨`

**S2 (5–12s)**
- VO: "ตอบช้าไปนิด ลูกค้าก็หาย จดสต็อกผิด ก็ขายของที่หมดไปแล้ว"
- CHAT (ยังไม่อ่าน): `พี่คะ Nike XL ยังมีไหม 👀`
- SUB: `ตอบไม่ทัน = เสียยอด · จดมือ = สต็อกมั่ว`

**S3 (12–18s)**
- VO: "ถ้ามี AI มาช่วยจัดการให้ทั้งหมด ตั้งแต่แชตยันส่งของล่ะ?"
- SUB: `พบกับ AI-BMS`

**S4 (18–34s)** — โชว์ของจริงในแอป
- VO: "ทุกแชทจาก LINE, TikTok, Facebook, Instagram และหน้าเว็บ รวมไว้ที่อินบ็อกซ์เดียว"
- CHAT ลูกค้า: `Nike XL มีไหม`
- CHAT AI: `มีค่ะ ✅ Nike Air ไซซ์ XL พร้อมส่ง 5 ชิ้น ราคา 3,200 บาท สนใจสั่งเลยไหมคะ?`
- CHAT ลูกค้า: `สั่ง 1 ชิ้นค่ะ โอนแล้วส่งสลิปนะ`
- CHAT AI: `รับออเดอร์แล้วค่ะ ✅ ตรวจสลิปเรียบร้อย · เลขพัสดุ TH12345 กำลังจัดส่ง 🚚`
- SUB (ไล่ทีละจังหวะ): `AI ตอบเอง` → `เช็คสต็อก + สร้างออเดอร์` → `ตรวจสลิปด้วย AI` → `ออกเลขจัดส่งอัตโนมัติ`

**S5 (34–44s)**
- VO: "คุณแค่ดูยอดขายโต… ระบบจัดการที่เหลือให้เอง"
- SUB: `ยอดขายโตขึ้น 📈 · ได้เวลาชีวิตคืนมา ☕`

**S6 (44–50s)**
- VO: "AI-BMS ไม่ใช่แค่แชทบอท แต่คือระบบธุรกิจ AI — เริ่มฟรีวันนี้"
- SUB: `AI-BMS · เปลี่ยนทุกแชท ให้เป็นยอดขาย`
- CTA: `เริ่มใช้ฟรี 👉 [เว็บของคุณ]/shop-signup`

## 7) 🎯 CAMERA MOVEMENT (ต่อช็อต)

- **1:** Slow **push-in** (dolly in) เข้าหาใบหน้า — สร้างความอึดอัด
- **2:** **Static** + สั่นเล็กน้อย (subtle handheld) ให้รู้สึกวุ่น
- **3:** **Rack focus** จากโต๊ะรกไปที่หน้าจอ
- **4:** **Whip pan / snap cut** ระหว่างภาพ (เร่งจังหวะปัญหา)
- **5:** **Pull-back** ช้าๆ ตอนโลโก้โผล่ (ปลดล็อกความรู้สึก โล่ง)
- **6:** **Smooth pan** ตามเส้น flow ของแชตเข้า inbox
- **7–9:** **Locked-off** + **punch-in** เล็กๆ ทุกครั้งที่มี "ติ๊กถูก" (เน้น payoff)
- **10:** **Gentle handheld** อบอุ่นเป็นธรรมชาติ
- **11:** **Tilt-up** ตามกราฟที่พุ่งขึ้น
- **12:** **Static** + โลโก้ **scale-pulse** เบาๆ

> จังหวะตัดต่อ: องก์ 1 ตัดถี่/กระตุก (วุ่น) → องก์ 2–3 ตัดลื่น จังหวะขึ้น (ปลดปล่อย)

## 8) 🔊 SOUND & BGM

**BGM (1 แทร็ก มี dynamic 3 ช่วง):**
- 0–12s: minimal/tense — เปียโนโน้ตเดี่ยว + ticking, โทนอึดอัด
- 12–18s: **build-up** (riser/swell) นำเข้าหา "drop"
- 18–44s: **upbeat modern / feel-good** (electro-pop เบาๆ 110–120 BPM, สดใส มั่นใจ)
- 44–50s: **resolve** อบอุ่น จบสวย + logo sting
- แนวอ้างอิงหา stock: *"uplifting corporate tech / happy startup"* (Epidemic Sound, Artlist)

**SFX map:**
- notification dings (ถี่ขึ้นเรื่อยๆ ใน S1) · sigh/ถอนหายใจ · clock tick (S2)
- whoosh + bright chime ตอนโลโก้ (S3)
- UI: keyboard clicks, message "pop", **cha-ching** (ปิดการขาย), **tick/✓ chime** (สำเร็จ), ระฆังเบาๆ ตอนแดชบอร์ดขึ้น (S4–S5)
- logo sting สั้นๆ ตอนจบ (S6)

**VO direction:** ผู้หญิงไทย อายุ 25–35 น้ำเสียงเป็นกันเองแบบเพื่อน เริ่มเห็นใจ→จบมั่นใจสดใส · เว้นจังหวะให้ SFX "ติ๊กถูก" หายใจได้

**Mix:** S1–S2 ให้ SFX นำ (ความวุ่น), S4 ให้ UI SFX ซิงก์กับภาพเป๊ะ, VO เด่นตลอด ดนตรี −12dB ใต้เสียงพูด
